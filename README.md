# Data Detectives Project Site

This repository hosts the student-facing Data Detectives project materials for GitHub Pages.

Files included:
- `index.html` — landing page with links to the project guide and workbook
- `data_detectives_project_guide.html` — teacher/student project guide
- `data_detectives_workbook.html` — student workbook with data entry and chart builder
- `.nojekyll` — prevents Jekyll processing on GitHub Pages

## Publish on GitHub Pages
1. Open the repository on GitHub.
2. Go to Settings → Pages.
3. Under Source, choose:
   - Deploy from a branch
   - Branch: `main`
   - Folder: `/ (root)`
4. Save.
5. Wait 1–3 minutes for the site to publish.

## Live URL
After publishing, the site will be available at:
